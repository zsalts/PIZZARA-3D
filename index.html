Para tener en cuenta

  • Cada paso guarda las posiciones; en 3D se animan de un paso al siguiente. Con “Recorrido” se ven todas las carreras: flechas punteadas = carreras, línea continua = pase de la bocha.
  • El proyecto se guarda solo en este navegador. Usá “Nube” o “Guardar archivo” para tener una copia o pasarlo a otro equipo.
  • Sistemas: tocá uno para aplicarlo (⌘Z deshace). “Guardar como sistema” toma las posiciones de las propias en el paso actual. “Cargar sistemas” lee un .json de otro entrenador; “Exportar” descarga los tuyos.
